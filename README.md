A simple Dice Roller application built using HTML, CSS, and JavaScript. Roll the dice and get random results.

## ✨ Features
- Roll one or multiple dice.
- Generate random numbers between 1 and 6.
- Display dice results dynamically.
- Interactive and user-friendly interface.
- Simple and clean design.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter the number of dice.
5. Click the Roll button to generate random results.
